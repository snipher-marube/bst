{# ── Quick-start guide ────────────────────────────────────────── #}

Okta

  1. In Okta Admin: Applications → Create App Integration → SAML 2.0
  2. Set Single sign-on URL to the ACS URL above.
  3. Set Audience URI (SP Entity ID) to the Entity ID above.
  4. Under Attribute Statements add: email → user.email, first_name → user.firstName, last_name → user.lastName
  5. Download the IdP metadata or copy the SSO URL and certificate from the Sign On tab.

Azure AD / Microsoft Entra

  1. In Azure Portal: Enterprise Applications → New Application → Create your own
  2. Choose Integrate any other application you don't find in the gallery.
  3. Under Single sign-on → SAML, set Reply URL to the ACS URL and Identifier to the Entity ID.
  4. Add attribute claims: emailaddress → user.mail, givenname → user.givenname, surname → user.surname
  5. Set attribute mapping fields above to: http://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddress etc.
  6. Download the Certificate (Base64) and copy the Login URL.

Google Workspace

  1. In Google Admin: Apps → Web and mobile apps → Add app → Add custom SAML app
  2. Download the IdP metadata or note the SSO URL, Entity ID, and certificate.
  3. Set ACS URL and Entity ID to the values above.
  4. Add attribute mappings: email → Basic Information → Primary email
