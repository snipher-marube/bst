Calculated Fields — arithmetic metrics evaluated at query time

Use sum(col), count(col), avg(col), min(col), max(col) on any column.

Examples:

  • sum(revenue) / count(user_id) → revenue per user
  • (sum(revenue) - sum(refunds)) / sum(revenue) * 100 → net margin %
  • sum(quantity) * avg(unit_price) → estimated GMV

In widgets: use type: "calculated" with an expression that references other aggregation names (e.g. total_revenue / total_users) or column functions directly.
