Step-by-step Setup Guide

{# Step 1 #}
  1. Go to console.cloud.google.com and sign in.
  2. Click Select a project → New Project. Give it any name (e.g. analyticsmeta).
  3. In the left sidebar go to APIs & Services → Library.
  4. Search for "Google Sheets API" and click Enable.
  5. Repeat for "Google Drive API" (needed to list spreadsheets).
{# Step 2 #}
  1. In the GCP Console go to IAM & Admin → Service Accounts.
  2. Click Create Service Account. Name it anything (e.g. sheets-reader).
  3. Skip role assignment — the service account only needs access to specific sheets you share with it.
  4. After creation, click the service account, go to the Keys tab.
  5. Click Add Key → Create new key → JSON. A .json file will download.
  6. Open the JSON file and copy its entire contents — you'll paste it below.
Security note: We encrypt this JSON with AES-256 (Fernet) before storing it. It is never logged or returned in API responses.
{# Step 3 #}
  1. Open the .json file you downloaded and copy the client_email value.
    It looks like: sheets-reader@your-project.iam.gserviceaccount.com
  2. Open the Google Sheet you want to connect.
  3. Click Share (top right) and paste that email address.
  4. Set permission to Viewer — read-only is enough and safer.
  5. Uncheck "Notify people" (no need to email a service account).
  6. Click Share.
{# Step 4 #}

The Spreadsheet ID is the long string between /d/ and /edit in the URL:

https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit

Copy just the highlighted portion — that is your Spreadsheet ID.
