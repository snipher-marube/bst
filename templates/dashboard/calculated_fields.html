How calculated fields work

Write an arithmetic expression using sum(col), count(col), avg(col), min(col), max(col) on any column name.

Example expressions:

  • sum(revenue) / count(user_id) → revenue per user
  • (sum(revenue) - sum(refunds)) / sum(revenue) * 100 → net margin %
  • sum(quantity) * avg(unit_price) → estimated GMV

To use a calculated field in a widget, add an aggregation with type: "calculated" and expression: "total_revenue / total_users" (referencing other aggregation names in the same widget).
